# Installation

Download the application file for your firmware from the [latest release](https://github.com/Th3Un1q3/flipp_pomodoro/releases/latest). The asset is named `flipp_pomodoro_{firmware}_{api_version}.fap`, where:

- `{firmware}` is `standard` for official firmware or `unleashed` for Unleashed firmware.
- `{api_version}` is the firmware API the application was built against. There is no simple mapping from API version to firmware version; the latest artifact targets the latest firmware API.

Copy `flipp_pomodoro_{firmware}_{api_version}.fap` to `/apps/Tools` on the Flipper's SD card, then open it from the `Applications` menu. You can add it to favorites for quick access.
